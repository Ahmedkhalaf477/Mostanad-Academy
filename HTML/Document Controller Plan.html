Document Controller Plan

Structured document management system for construction & infrastructure projects

1. Project Information

  • Project Name: ____________________
  • Client: ____________________
  • Consultant: ____________________
  • Main Contractor: ____________________
  • Plan Revision: Rev.00

2. Purpose

  • Organize and control all project documents.
  • Ensure latest approved revisions are used.
  • Maintain document traceability and archiving.
  • Implement a standardized coding system.

3. Scope

  • Drawings
  • Letters
  • RFI
  • Material Submittals
  • Inspection Requests
  • Reports
  • Minutes of Meeting

4. Document Control Procedure

  • Receive and register incoming documents.
  • Review and assign document code.
  • Distribute to concerned parties.
  • Track revisions and approvals.
  • Archive electronic and hard copies.

5. Revision Control

  • Rev.00 = Initial Submission
  • Rev.01 = Updated After Review
  • Rev.02 = Final Approved Version

6. Document Coding System

Format:

PROJECT-DISC-TYPE-AREA-SEQ-REV

Example:

ABC-CIV-DRW-Z01-001-Rev00

7. Discipline Codes

  • CIV = Civil
  • ARC = Architectural
  • ELE = Electrical
  • MEC = Mechanical
  • INF = Infrastructure
  • QA = Quality
  • HSE = Safety

8. Document Type Codes

  • DRW = Drawing
  • LET = Letter
  • MAT = Material Submittal
  • RFI = Request For Information
  • IR = Inspection Request
  • MOM = Minutes of Meeting
  • RPT = Report

9. Archiving System

  • Electronic Archiving using Server / SharePoint / Aconex.
  • Hard copy filing with clear labels and indexing.

10. Logs

  • Incoming Log
  • Outgoing Log
  • Drawing Log
  • Submittal Log
  • RFI Log
  • IR Log

11. Backup

  • Daily backup on cloud and local server.
  • Periodic backup verification.
