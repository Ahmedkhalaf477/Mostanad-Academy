Document Archiving System in Document Control

Professional guide for managing and archiving project documentation

1. Introduction

An archiving system is used to organize, store, and retrieve project documents efficiently. It ensures that all project records are controlled, traceable, and compliant with standards in construction and engineering projects.

2. Types of Archiving Systems

  • Digital Archiving
  • Aconex
  • SharePoint
  • EDMS (Electronic Document Management System)

  • Physical Archiving
  • Archive rooms
  • Filing cabinets
  • Project document centers

3. Document Classification

  • Technical Documents
  • Correspondence
  • Reports
  • Approvals & Submittals
  • Contracts & Legal Documents

4. Coding System

Each document must have a unique code for easy tracking and retrieval.

PRJ-DC-001-REV0
  • PRJ = Project Code
  • DC = Document Control
  • 001 = Sequence Number
  • REV0 = Revision Number

5. Workflow Process

  • 1. Document Creation
  • 2. Review & Approval
  • 3. Registration in System
  • 4. Distribution
  • 5. Archiving (Digital & Physical)
  • 6. Retrieval when needed

6. Benefits

  • Improved document tracking
  • Faster retrieval of information
  • Reduced risk of data loss
  • Better compliance and audit readiness
  • Organized project communication

7. Conclusion

A well-structured archiving system is essential for efficient document control management and successful project delivery.
